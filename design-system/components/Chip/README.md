# Chip

Etiqueta de tema com ícone pequeno e colorido, sobre fundo branco translúcido. Funciona sobre fotos e faixas coloridas.

- Consumidor fornece: o texto e um ícone de 14px preenchido com uma cor da marca.
- Em nuvem de tags, `gap: space-2`, quebrando linha.
- Não é clicável. Para ação, use `mfb-btn`.
