# Button

Botão em pílula grossa, rótulo em caixa alta. `primary` é coral com texto `on-accent`; `outline` é branco com contorno coral e texto `coral-ink`.

- Classes: `mfb-btn` + `mfb-btn--primary` | `mfb-btn--outline`; `mfb-btn--sm` para 38px.
- Consumidor fornece: o rótulo, em verbo de ação ("Quero começar", "Ver perguntas").
- Um `primary` por bloco. Par comum no hero: `primary` + `outline` lado a lado.
- Nunca texto branco sobre coral. Para links, use `<a class="mfb-btn">`.
