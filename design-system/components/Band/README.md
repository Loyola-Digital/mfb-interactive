# Band

Faixa de seção de largura total com borda superior ondulada. A página alterna faixas coloridas e brancas, como nas referências.

- Cores: `--coral` (coral-tint), `--leaf` (verde cheio), `--yellow` (yellow-vivid), `--sky` (sky-tint).
- Nunca duas faixas da mesma cor seguidas. Uma faixa verde ou amarela cheia por página.
- Padding vertical `space-8` (64px no mobile).
