# Card

Card branco com sombra suave e raio grande, para blocos de explicação (Problema, Método, benefício).

- Partes: ilustração ou personagem opcional no topo, título `h3` em `display`, parágrafos curtos.
- Versão sem sombra e tingida: `mfb-card--tint` + `--coral` | `--leaf` | `--yellow` | `--sky`, para cards sobre `surface`.
- Sobre faixa colorida use o branco; sobre `surface` use o tingido.
- Em dupla ou trio, `gap: space-5`.
